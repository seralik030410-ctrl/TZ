# Ритм — личный ежедневник

Мобильный ежедневник: сегодня, расписание, задачи, проекты, финансы, дневник и
аналитика. Дополнительно доступны агентство, журнал сделок с золотом и долги.
ИИ и подключение к брокеру не используются.

## Локальная разработка

Нужны Node.js 20+ и MySQL/MariaDB. Создайте локальную базу данных и задайте в
`.env` подключение и пароль входа (образец — `.env.example`):

```dotenv
DATABASE_URL=mysql://user:password@127.0.0.1:3306/ritm
PLANNER_PASSWORD=replace-with-a-local-password
APP_ID=ritm
APP_SECRET=replace-with-a-long-random-secret
```

Затем выполните:

```bash
npm install
npm run db:migrate
npm run dev
```

Откройте `http://localhost:3000`. Для быстрого локального просмотра в текущей
рабочей копии настроены временные тестовые доступы; не используйте их в сети.

## Railway

Репозиторий настроен на Dockerfile builder. Добавьте MySQL и web-сервис,
установите `DATABASE_URL` на URL этой базы и задайте уникальные `PLANNER_PASSWORD`,
`APP_ID` и длинный случайный `APP_SECRET`. В `railway.toml` pre-deploy запускает
`npm run db:migrate`, а `/health` проверяет доступность MySQL. После проверки
переменных Railway можно выполнять deployment. В этом проекте deployment ещё не
запускался; реальные аккаунты и данные не подключались.

До загрузки реальных данных настройте регулярные резервные копии MySQL и проверьте
восстановление копии в отдельную базу. Миграции сохраняются в `db/migrations`;
не заменяйте production миграции командой `db:push`.

## Проверки

```bash
npm run check
npm run test
npm run build
npm start
```

`npm start` запускает production-сборку и требует те же переменные окружения.

## Реализованные части

- День: события, свободные окна, задачи, главные задачи и предупреждения.
- Задачи: список, доска и матрица; подзадачи и зависимости; перетаскивание мышью,
  касанием и клавиатурой, анимация порядка и отмена последнего переноса.
- Проекты, этапы, фокус-сессии, недельный обзор и график завершений задач.
- Доходы, расходы, бюджет, заметки и офлайн-очередь быстрых записей.
- Агентство: клиенты, сделки, оплаты, визы и перелёты.
- Золото: сделки, баланс, дневные ограничения и журнал обходов.
- Долги: валютные остатки, платежи и связанная с платежом финансовая запись.
- PWA, экспорт JSON/CSV, светлая и тёмная темы.
