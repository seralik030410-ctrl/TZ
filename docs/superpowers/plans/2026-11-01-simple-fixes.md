# Короткий план правок «Ритма»

1. Проекты: добавить «Новая задача», выбор этапа, редактирование задач/подзадач прямо из ветки и редактирование параметров проекта.
2. Деньги: ожидание оплаты отдельно от факта; кнопки «Деньги получены» и «Ещё не получено»; ожидаемая сумма не увеличивает доходы и бюджет.
3. Формы: исправить пустые категории и валюты, сброс несовместимой категории при смене типа, скрытую привязку к паре при общем доступе, редактирование быстрого результата «Золота».
4. Расписание миграцией: 01.11–31.12.2026, пары Пн–Сб 08:00–11:50 и 13:00–16:50, воскресенье без пар; каждый Пн «Запись в Корео» 09:00–10:00. Идемпотентно, без изменения профиля друга. Устаревший seed не должен возвращать воскресенья.
5. Доступ: в настройках понятная инструкция «Пригласить в общее пространство» → скопировать одноразовую ссылку → друг создаёт свой профиль; доступ к проектам/задачам выбирается отдельно.
6. Отдельно остаётся очистка: обратимый архив остальных личных данных с сохранением пар и Корео. Общая очистка сейчас не выполнена и не включена в автоматический деплой; существующий архив задач не заменяет очистку всех разделов. Профили и общие данные не удаляются.

Пункты 1–5 внесены в код. Ранее добавленные расписание сверху главной, задачи/подзадачи внутри пары, обязательные платежи и лимиты сохраняются. Обновление расписания переносит привязки задач и исключения на новые пары; воскресные задачи остаются отдельными задачами. Для завершённых проектов исправлена подпись статуса.

На отдельной локальной MariaDB проверены миграции/повторный запуск seed, перенос привязок задач, редактирование проекта и задач через API, ожидаемая/полученная оплата, повторное подтверждение без дублей, одноразовое приглашение и изоляция данных друга.
