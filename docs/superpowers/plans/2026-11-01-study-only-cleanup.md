# Очистка с сохранением расписания

Цель: убрать личные данные пользователя в обратимый архив, сохранив занятия, запись в Корео, профили и общие данные.

1. В одной транзакции сохранить снимок активных личных записей и скрыть их. Учесть проекты, этапы, задачи, блоки, шаблоны, финансы, обязательные платежи, дневник, историю, агентство, золото и долги.
2. Сохранить занятия и связанные исключения расписания, а также событие «Запись в Корео». Другие личные события включить в архив.
3. Не менять общие проекты, задачи и блоки; перед архивированием проверить связи личных записей с общими, чтобы не повредить доступ другу.
4. Предусмотреть восстановление только записей конкретного архива и проверку конфликтов с изменениями после очистки.
5. Защитить очистку от повторной отправки старых офлайн-операций: текущий task_epoch защищает задачи, но не финансовые и другие записи. До решения этой проблемы не запускать очистку базы.
6. Проверить очистку, восстановление, повторный запуск и изоляцию друга на отдельной локальной базе. Затем выполнить очистку Railway и проверить результат.

Для всей очистки добавлен отдельный архив; прежний архив задач используется независимо.

Реализовано: миграция 0016 скрывает личные записи и сохраняет их идентификаторы в personal_cleanup_archive. Исходные строки остаются в БД. Восстановление: node scripts/restore-study-cleanup.mjs с DATABASE_URL нужной базы; при изменении архивной строки операция откатывается. Старые офлайн-операции всех разделов удерживаются по версии. Проверены локальная очистка/восстановление, общие записи, данные друга, пары/Корео, 69 тестов и API с устаревшей финансовой очередью. Миграция выполняется один раз при публикации.
