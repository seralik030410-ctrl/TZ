# Пустая категория дохода: исправление

Причина: AppSelect преобразовывал `<option>Проекты</option>` в value="", хотя native select использует текст варианта, если value не указан. Все категории получали одинаковое пустое значение, их подписи склеивались, API отклонял пустую category. Это также затрагивало валюты и другие списки с неявными значениями.

Исправлено в `src/lib/selectOptions.ts` и `src/components/FormControls.tsx`: пропущенный value берётся из текста, явные value="" и value={0} сохраняются. QuickAdd проверяет пустую категорию до отправки и показывает понятное сообщение.

Проверки: новые тесты воспроизвели два падения на старой реализации и прошли после изменения; всего 58 тестов PASS, TypeScript/build/ESLint затронутых файлов PASS. В локальном browser fixture выбраны Доход → 2500 → Проекты → AZ Plus. DOM подтверждает отдельные варианты Проекты/Агентство/Прочее и непустое значение «Проекты». Денежная операция не отправлялась, production-данные не изменялись. [Снимок](../evidence/2026-11-01/income-category-fixed.png).
